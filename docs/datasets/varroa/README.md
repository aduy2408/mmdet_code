# Varroa dataset protocol

## Dataset identity

- Task: one-class bounding-box detection.
- Class: `varroa`.
- Format: COCO JSON.
- Canonical local root: `mmdetection/data/varroa_coco/`.
- Split seed: not generated by the MMDetection launcher. The committed
  `train.json`, `val.json`, and `test.json` files are the canonical split.

## Required files

```text
mmdetection/data/varroa_coco/
├── annotations/
│   ├── train.json
│   ├── val.json
│   └── test.json
└── images/
    ├── train/
    ├── val/
    └── test/
```

The COCO category must be `varroa`, and every image referenced by each JSON
file must exist below its corresponding image directory.

## Preprocessing

The current SR-TOD Faster R-CNN setup uses the normal COCO path:

- `LoadImageFromFile`
- `LoadAnnotations(with_bbox=True)`
- `Resize(scale=(1333, 800), keep_ratio=True)`
- random horizontal flip with probability `0.5` for training
- `PackDetInputs`

This dataset does **not** use corner-window cropping or TinyPerson's custom
loader.

## Evaluation

Use `CocoMetric(metric='bbox')` with the matching split annotation file. Report
COCO bbox `mAP`, `AP50`, and `AP75`. Do not evaluate Varroa with the TinyPerson
tile-merging evaluator.

## Common mistakes

- Do not change the one-class label to a generic `person` label.
- Do not point the test evaluator at the validation annotation.
- Do not infer the split from a checkpoint or work-directory name.
